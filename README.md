# DG-LAB 3.0 Web 控制器

这是一个基于 ESP32 的 Web 控制器项目，旨在通过浏览器界面控制 DG-LAB 3.0 型号的脉冲主机设备。该项目参考了 DG-LAB 官方开源项目 [DG-LAB-OPENSOURCE](https://github.com/DG-LAB-OPENSOURCE/DG-LAB-OPENSOURCE)的WEBUI界面，并进行了适配和扩展。

---

## 项目功能

- **设备扫描与连接**：蓝牙扫描并连接 DG-LAB 3.0 型号的脉冲主机设备。
- **波形控制**：选择并发送预定义的波形到设备的 A/B 通道。
- **强度调整**：实时调整设备的 A/B 通道强度。

断线恢复：意外断开时会保留发送意图，并仅在重新连接到相同 BLE 地址及地址类型的设备后恢复波形。手动断开或手动选择另一台设备时，发送状态保持停止，需要在界面中重新点击“开始发送”。

---

## 默认 Wi-Fi 热点信息

在设备启动后，ESP32 会创建一个名为 `ESP32-Controller` 的 Wi-Fi 热点，默认密码为 `12345678`。该热点的 SSID 默认为隐藏状态，需在终端设备上手动输入网络名称进行连接。连接成功后打开浏览器，访问 `http://192.168.4.1/` 即可进入控制界面。

## 使用说明

### 硬件要求

- ESP32开发板
- 郊狼主机
- 用来连接脉冲主机的蓝牙设备

### 软件要求

- [PlatformIO](https://platformio.org/) 环境（PlatformIO IDE 或 PlatformIO Core）。

### 安装步骤

1. 下载或克隆本项目代码。
2. 使用 PlatformIO 打开项目根目录。
3. 连接 ESP32 开发板，构建并上传固件：

   ```bash
   pio run
   pio run --target upload
   ```

4. 如需查看串口日志，运行：

   ```bash
   pio device monitor
   ```

5. 上传完成后，ESP32 会启动并创建一个名为 `ESP32-Controller` 的 Wi-Fi 隐藏热点。
6. 在终端设备上手动添加并连接该 Wi-Fi 热点。在浏览器中访问 `http://192.168.4.1/`，即可进入控制界面。

> 固件包含 Web 与 BLE 功能，体积超过默认应用分区。项目已使用 `huge_app.csv`（3 MB 应用区）分区方案，因此不支持 OTA 双分区升级。
