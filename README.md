# DG-LAB 3.0 Web 控制器

这是一个基于 ESP32 的 Web 控制器项目，旨在通过浏览器界面控制 DG-LAB 3.0 型号的脉冲主机设备。该项目参考了 DG-LAB 官方开源项目 [DG-LAB-OPENSOURCE](https://github.com/DG-LAB-OPENSOURCE/DG-LAB-OPENSOURCE)，并进行了适配和扩展。

---

## 项目功能

- **设备扫描与连接**：蓝牙扫描并连接 DG-LAB 3.0 型号的脉冲主机设备。
- **波形控制**：选择并发送预定义的波形到设备的 A/B 通道。
- **强度调整**：实时调整设备的 A/B 通道强度。

---

## 默认 Wi-Fi 热点信息

在设备启动后，ESP32 会创建一个名为 `ESP32-Controller` 的 Wi-Fi 热点，默认密码为 `12345678`。您可以使用手机或电脑连接该 Wi-Fi 热点，连接成功后打开浏览器，访问 `http://192.168.4.1/` 即可进入控制界面。

---

## 使用说明

### 硬件要求

- ESP32开发板
- 郊狼主机
- 用来连接脉冲主机的蓝牙设备

### 软件要求

- Arduino IDE 或 PlatformIO 环境。

### 安装步骤

1. 下载或克隆本项目代码
2. 在Arudino IDE中打开项目文件并上传代码到ESP32
3. 上传完成后，ESP32 会启动并创建一个名为 ESP32-Controller 的 Wi-Fi 热点。
4. 连接该 Wi-Fi 热点。在浏览器中访问 http://192.168.4.1 ，即可进入控制界面。
